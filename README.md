# 뽑아뽑아 로또볼

볼 개수만큼 공이 생기고, 로또 추첨기처럼 섞은 뒤 정한 개수만큼 하나씩 뽑는 게임. 설치 없이 브라우저에서 돌아가고, 폰 홈 화면에 앱처럼 설치할 수 있습니다.

- 볼 개수: 2~45개, 뽑을 개수: 1개~볼 개수
- 볼마다 이름을 붙일 수 있고, 비워 두면 번호만 나옵니다.
- 뽑기는 아직 기계 안에 남은 볼 중에서 무작위(crypto.getRandomValues)로 고릅니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 (화면, 추첨기, 음악) |
| `manifest.webmanifest` | 폰에 설치할 때 쓰는 앱 이름·아이콘 정보 |
| `sw.js` | 오프라인에서도 열리게 하는 서비스 워커 |
| `icons/` | 앱 아이콘 |

## 폰 앱으로 쓰려면

주소를 폰에서 연 뒤:

- **안드로이드(Chrome)**: 화면 위의 "앱 설치" 버튼, 또는 메뉴 → 홈 화면에 추가
- **아이폰(Safari)**: 공유 버튼 → 홈 화면에 추가

## 참고

- 저장한 게임은 각 기기의 브라우저에만 보관됩니다. 친구에게는 "카톡으로 공유" 링크로 보내세요.
- 음악과 효과음은 브라우저에서 직접 합성하므로 음원 파일이 없습니다.
- 비상업적 용도로 자유롭게 사용할 수 있습니다.
